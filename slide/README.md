# Slide 模板与素材

幻灯片模板与工程框图素材目录：

## 模板与资源索引

1. `Template-zju_Typst/`：基于 Typst (Touying) 的浙江大学学术报告/文献分享模板，支持实时预览与毫秒编译。
2. `Template-zju_Beamer/`：基于 LaTeX Beamer 的浙江大学求是蓝标准幻灯片模板。
3. `ee_ctrl_fig.pptx`：电气工程控制框图与拓扑图素材（已修复解除 OLE 锁定，避免 Mac 端双击报错）。
4. `ee_ctrl_fig.vsdx`：从源文件中提取的独立 Microsoft Visio 矢量图纸，可直接使用 Draw.io 或 Visio 编辑。
5. `ee_ctrl_fig_top.svg`：主拓扑框图无损矢量 SVG。
6. `ee_ctrl_fig.ppt`：原始 97-2003 格式母版文件。
7. `figs.pptx`：常用学术与图表素材。
8. `template.pptx`：通用学术/商务汇报 PPT 模板。
